# VIBE CODING BOOTCAMP — 講義サイト

AIドリブンのシステム開発集中プログラム（全8回 × 60分）の進行用サイト。

## バージョン

- **v2（このフォルダ）**: LIAR GAMEテーマ ─ 黒×金×赤、重厚明朝（Shippori Mincho B1）＋
  彫金セリフ（Cinzel）、メタリックゴールドのシマー演出。
- **v1（../vibe-coding-bootcamp_v1）**: ミリタリーブートキャンプテーマ（緑）。機能は同一。

## 起動方法

**[START_BOOTCAMP.bat](START_BOOTCAMP.bat) をダブルクリック**するだけ。
ローカルサーバー（ポート8888）が立ち上がり、Chromeで自動的に開く。
黒いウィンドウを閉じるとサーバーも停止する。

手動で起動する場合:

```
python -m http.server 8888
```

※ `index.html` 直開きでも動くが、ニューラル音声が使えずTTSフォールバックになる。
GitHub Pages にそのまま置けば公開も可能（音声ファイルごとアップロードすること）。

## 機能

- **MISSION SELECT（トップ）**: 8回分のカードから回を選択。完了スタンプは localStorage 保存。
- **タイムライン**: 各アクティビティに経過時刻・所要分・種別・担当ハットを表示。
- **自動解説ブリーフィング（FDE風）**: 各アクティビティの「▶ START」で、内容を解説するスライドが
  **音声ナレーション付きで自動再生**される（Web Speech API / 日本語音声）。
  - クリック / `Space` / `→` で手動進行、`←` で戻る、`Esc` で閉じる
  - 「🔊 自動再生」トグルで音声＋自動進行のON/OFF、「⏭ スキップ」で最終スライドへ
  - 最終スライドの「⏱ タイマー START」でそのままアクティビティのタイマーへ突入
  - 各回ページ上部の「▶ MISSION BRIEFING」でその回全体の概要も自動解説
- **タイマー**: ブリーフィングの最後から該当時間のフルスクリーンタイマー起動。
  残り3分で黄色、1分で赤、終了でビープ＋点滅。Space=開始/停止、Esc=閉じる。±1分調整・プリセットあり。
- **ハットドック（右下）**: 現在のハット（🎓講師/🧢メンター/💼クライアント）を投影表示。クリックで切替。
- **お題ガチャ**: AI駆動開発100本ノック（第一弾・第二弾）から難易度別にお題をランダム支給。そのまま25分スプリント開始可能。
- **印刷**: 各回ページを Ctrl+P で講師用進行表として印刷可能（操作UIは自動非表示）。

## 音声（神クオリティ・ナレーション）

ナレーションは2段構え：

1. **事前生成ニューラル音声（推奨・生成済み）**: `audio/` フォルダにMicrosoftニューラル音声の
   MP3が165本入っている。`audio/manifest.json` があれば自動でこちらを再生。
   - ナレーター：ja-JP-Keita（低音男性・LIAR GAME風に -25Hz ピッチ）
   - クライアントのつぶやき：ja-JP-Nanami（別人と分かる軽い声）
2. **ブラウザTTSフォールバック**: manifest が無い/テキストが見つからない場合は自動で従来のTTS。

### 台本を変えたら再生成

```
pip install edge-tts json5 truststore
python generate_voice.py
```

差分のみ生成される（生成済みはスキップ）。声・速度・ピッチは
[generate_voice.py](generate_voice.py) の `VOICES` を編集して再実行。
全部作り直すときは `audio/` を削除してから実行。

※ `fetch` を使うため、音声再生にはローカルサーバー経由でのアクセスが必要
（`python -m http.server`）。`index.html` 直開きではTTSフォールバックになる。

## 開催日ロック

各EPは [data.js](data.js) の `date`（開催日）の**前日 0:00 に解禁**される。
解禁前はトップのカードが 🔒（タイトルは「？？？」表示）になり、ページを開いても CLASSIFIED 画面のみ。

- スケジュール: EP.01=6/12(金)、以降毎週金曜（EP.02=6/19 … EP.08=7/31）。変更は data.js の `date` を書き換えるだけ
- **講師モード（受講者には内緒）**: ヘッダーのロゴを**素早く7回クリック**すると全EPのロックを解除／再ロックできる
  （localStorageに保存。ONの間はヘッダーに「🎓講師モード」バッジが出る）

## 運用メモ

- タイマー画面はアクティビティ起動時にそのハットへ自動切替される。物理ハットの被り替えと同期させること。
- EP.04 の「要件変更発動」がブートキャンプの山場。現実的な変更（対象デバイス・利用者追加）を演じる。
- EP.07 までに受講者の GitHub アカウント準備を事前アナウンスしておく。
